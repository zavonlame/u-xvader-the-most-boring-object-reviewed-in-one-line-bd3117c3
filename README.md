One funny, true line reviewing the dullest everyday object I could name — a doorstop.

**Entry (124 chars, 1 line):**

> One star. The doorstop has held this door open for six years without a single thank-you. Its reward: kicked into the corner.

The joke comes from how a doorstop really behaves: it holds a door open for years, nobody thanks it, and the only attention it ever gets is being kicked into a corner.

## How it works

`main.ts` (Node 22, standard library only) embeds the review as a literal, checks it against the gate (1–200 characters, single line, non-blank), then writes it to `/output/entry.txt`.
